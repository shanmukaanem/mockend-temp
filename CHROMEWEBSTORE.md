Last updated: 2026-11-27. Release: 0.0.10. Submission status: draft, not published.

## Store listing

**Extension name:** Mockend

**Short description:** Test browser behavior with reusable JSON API mocks, payload matching, and simulated network failures.

**Detailed description:**

Mockend records requests in an app tab you select and lets you replace API responses to test how your web application behaves.

Create mocks from captured responses or add your own. Match endpoint paths, methods, query values, and JSON fields. Change response bodies, HTTP statuses and reason phrases, delays, headers, or network failures. Switch between your app's Envs without rewriting endpoint rules.

Keep apps in separate profiles, each with its own Envs, Flows, settings, and request history. Merge apps or split selected Envs into a separate app. Search and filter traffic, inspect responses, copy cURL commands, and exchange local Mockend backups, Postman collections, mock handlers, or OpenAPI examples.

Open your app, open Mockend, start recording, and trigger an API request. Choose Mock at the end of its request row, edit the response, save, and start mocking. Stop mocking to return to the server's responses. No account or payment is required.

Recordings and configuration stay on your computer. Mockend does not send telemetry, recordings, or configuration to its developer. Review files and clipboard content before sharing them.

**Category:** Developer Tools

**Single purpose:** Record and replace HTTP responses in a developer-selected browser tab to test a web application.

**Primary language:** English

## Permissions justification

| Permission | Type | User-facing justification |
| --- | --- | --- |
| debugger | permissions | Read requests and responses in the tab the developer selects and replace matching responses with their configured mocks. Chrome displays its debugging notice while attached. |
| storage | permissions | Save app profiles, mock rules, Flows, Envs, settings, and the local legacy-configuration backup. |
| tabs | permissions | Identify the selected app tab by title and URL, follow its navigation, and open a configured app when its profile is selected. |
| sidePanel | permissions | Display recording, traffic inspection, and the mock editor beside the selected app. |
| clipboardWrite | permissions | Copy cURL commands, backups, and supported transfer content only when the user chooses Copy. |
| None | host_permissions | No broad or domain-specific host permissions are requested. Recording and mocking use the selected debugger target. |

## Privacy and data use

**Local data handling:** yes. **Automatic off-device collection by the developer:** no.

Recorded URLs, methods, headers, request bodies, response bodies, statuses, and tab titles are processed locally. Website content and activity in the selected tab can contain personal information, authentication information, communications, location, health, or financial data if these are present in the traffic the developer records. Do not claim the tool cannot encounter sensitive data in the dashboard disclosures.

App/profile configuration, optional launch URLs, and the pre-upgrade backup use local extension storage. Request history and view preferences use local IndexedDB and local storage. There is no advertising, analytics, sale of data, remote executable code, account system, or developer-operated upload service. User-initiated exports and clipboard copies can contain sensitive data. Unmocked app traffic still goes to the app's own servers.

- Data is not sold to third parties.
- Data is used only for the extension's recording and mocking features.
- Data is not used to determine creditworthiness or for lending.
